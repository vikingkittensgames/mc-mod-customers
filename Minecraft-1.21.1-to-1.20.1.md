# Minecraft 1.21.1 to 1.20.1 Migration Notes

This document records version-specific differences for the Minecraft 1.20.1 Forge and Fabric branch. Shared behavior
and compatibility helpers are documented in `Compatability.md`.

## Build configuration

| Setting | Minecraft 1.21.1 | Minecraft 1.20.1 |
| --- | --- | --- |
| Java source, test, and runtime toolchain | 21 | 17 |
| GeckoLib | Compatible 4.x, starting at 4.8.4 | Compatible 4.x, starting at 4.8.4 |
| Gecko asset directories | `geo` and `animations` | `geo` and `animations` |

The established Architectury Loom build itself is unchanged. Loom's Gradle daemon runs with the JDK version required
by that plugin, while compilation, tests, generated bytecode, and Minecraft runs use the Java 17 project toolchain.

## Appearance behavior

The appearance API carries loader-neutral context properties and optional villager names on both branches. Names are
stored as normal Minecraft custom names. Minecraft 1.20.1 uses `ComponentCUtils` to adapt its older component JSON
serializer; this is an implementation difference and does not change skin-pack JSON or player-visible behavior.

The embedded MCA implementation has been removed. MCA Reborn, Millénaire, and MineColonies integrations are separate
appearance mods. There is currently no MCA Reborn appearance add-on for Minecraft 1.20.1.

GeckoLib skin definitions have the same player-facing behavior, configuration fields, resource locations, and
installation split on 1.20.1 and 1.21.1. Server administrators can use one combined data/resource pack on either
version without editing its definitions. GeckoLib is optional and client-side; without it, ordinary skins remain
available and Gecko skins are excluded from selection.

## Implementation differences

Minecraft 1.20.1 renderers operate directly on entities and GeckoLib 4's entity renderer API. Newer Minecraft branches
may use render-state APIs, but that difference stays inside the renderer bridge. The shared code owns animation-state
selection, head rotation, geometry and sitting-pivot calculations, resource expansion, and overhead-item positioning.

Minecraft 1.20.1 uses `defineSynchedData()` and compound tags for appearance context. Forge and Fabric share the same
selection and persistence logic while retaining loader-specific registration and data-pack lifecycle adapters.
